# Scholarship Management System (WIP)

This project is intended to manage the scholarship granting process of a school or any educational institution.

The current implementation of the app provides the capability to manage students, exams, and exam records.

The goal of this system is to provide visibility to the patrons who offer financial support to schools/educational institutions and enable scholarship administrators to manage the scholarship process efficiently. Patrons will be able to view the progress of the students they are assisting, which will encourage them to continue their support and motivate others to contribute financial assistance.
